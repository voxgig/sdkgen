examples: |
  The rule is decided in example.ts by result style, through two functions.
  - interrupts(): true for throw, raise, die and wrapped. wrapped is defined as 'a failure throws', and none of the nine uses it.
  - checksItself(): false only for errslot. In pair and union the error comes back with the value, so the call printer must take the result apart to bind it: go checks err and panics, rust unwraps, zig switches. In errslot the value is bound whether or not the slot was set.
  
  What it does:
  - In a non-interrupting style (pair, errslot, union), refOpBlock adds a print of the record after load and remove. The provider prints the check: c guards it with `if (result)`; rust prints after `.unwrap()`; go and zig already printed it through unusedError.
  - In errslot, writeBlock wraps each write in an attempt, and topQuickText keeps the attempts that bare() used to strip.
  - c's attempt printer now leaves out an empty else. c's hoisted field read now finds a call nested inside a check, without which created_id disappeared.
  
  Result:
  - c REFERENCE load and remove get the NULL check and the read of the record back.
  - c root quick start: the list is checked and err reset before the load runs.
  - c tutorial write step: each call is followed by `if (err) { fprintf; err = NULL; }`.
  - Lanes: c DOC 6/6, go README 12/12, rust DOC 6/6, zig doc 6/6, all unchanged.
  
  blockident.js counts, over the OLD blocks that printed or checked (base out/new, then mine):

  - rust: byte-identical 0 -> 43 of 44, same one block absent.
