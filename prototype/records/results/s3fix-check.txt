masking: |
  Masking (tools/facts.js) replaces every declared fact value in a unit with a label listing every path where this language declares that value, for example `⟦ref.none⟧` or `⟦collection⟧`. It does this in three places: a whole code span, a fragment value (with a space, backtick or leading dot), and a bare word only in the prose slots (collection, noun, entityNoun, maps). Each reference language's units are masked with that language's own facts. A 'reworded' or 'added' unit whose masked text equals a reviewed reference unit is recorded as `shared:<ref>:<id>` with no person involved (for a pair, the OLD side must match too).
  
  So the mask removes exactly the fact value. Whether the value is TRUE is never looked at, so a wrong value in the same slot is accepted. Only the guard (for derived and cited facts) and the fact sheet (which lists values but fails only on a missing account) speak to truth. Facts counted as 'language' (none, maps, lits) and 'convention' (noun, entityNoun, heading, named, prints) are never compared with the runtime.
  
  RAN: in rb, a wrong none, maps or noun made 5 classes shared automatically, and a wrong lits.false made the direct sentence shared:py, all with the guard passing. Other classes flagged them only because OLD rb had stated the true value (a new token, a missing heading, a reworded pair).
  
  READ: shared code also states some facts by a default nobody declares: `lit(r,false)` in ReadmeRef.ts:177-178 prints `false` unless lits is declared. perl's direct returns 'ok' => 0 (Main.fragment.pm:226,245,260,264,310), OLD perl already prints `false` (24 times in B/perl/REFERENCE.md), and no table row or PORTING row mentions it. So a perl port that declares nothing would print a false sentence, matched as shared, with no token new to the language, no fact on the sheet and no guard check: nothing else would show it.
