- **Merge when green.** A pull request opened for this work merges once CI
  passes on every OS and no review thread is open.
  - Codex reviews every PR in sdkgen and apidef, usually within 15 minutes of

- **Verify every review finding.**

  squashed.

- **apidef commits** carry no trailers and no tool identifiers.

**The recorded user-agent (`-R`).**
- **The leak:** `createLiveTransport` records the request's `user-agent`
  verbatim. With `auth.name: user-agent` in `sdk-test-control.json`, the
  credential goes out in `LIVE REQUEST`, `LIVE STEP` and `LIVE SUMMARY`.
- **The fix:** never record the raw value. Pass it through the client's
  `clean`, or record a label: the SDK default, the configured agent, or
  "configured".
- **Same class:** `unreadableBody` in `ResultBodyUtility` puts the sent
  user-agent into its error message. Check that the message is masked on
  every exit, `direct()`'s `ok: false` included.
- In ts and js.

**The action-only create (`-I`).**
- **The defect:** the `op === 'create'` block rebuilds the input from
  `synthesizeInput` or `{}` and restores only path parameters. So `$action`
  is lost, and `makePoint` answers `point_action_required`.
- **The fix:** carry `resolved.$action` into the rebuilt input, in ts and js.

**The body preview (`-X`).**
- **The defect:** `preview()` cuts the body to 160 characters before
  `clean` runs, so a secret that crosses the boundary leaks as a prefix.
- **The fix:** clean the whole flattened body, then bound it, in ts and js.

**PHP `markTestSkipped` (`-b`).**
- **Why it is not a defect:** the generated `composer.json` requires
  `phpunit/phpunit ^11.0`. PHPUnit 11 defines `markTestSkipped` on
  `PHPUnit\Framework\Assert` itself, as `final public static function
  markTestSkipped(string $message = ''): never`.
- **What to do:** confirm that a lenient PHP live run skips through it, and
  reply with that.

**What remains on #320.**
1. **Tests,** each with a negative control on 33f582c1:

### `claude/live-allof`: #319

Two commits: a6a82a1d and 356f2e1e.

**The change:** `synthesizeInput`, in the ts and js live contracts, now builds
an `allOf` by the rule `definitionPlan` settled in #317:
1. Merge the object parts, when there are any.
2. Otherwise take the value a part declares: an example, then an `enum`
   value, then a default.
3. Otherwise take the first part that gives a value.

So SMSAPI's required `sender`, `allOf: [$ref Id, { description }]`, no
longer blocks the create. Shared rows in `livecontract.test.ts` run against
both twins.

**Overlap:** it touches only `live-contract.{ts,js}`, which #320 does not
change.

**What remains:** the full suite, the gates, and a PR with `Fixes #319`.
