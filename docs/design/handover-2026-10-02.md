## Working rules the user set

- **Merge when green and reviewed.** A pull request opened for this work
  merges once CI passes on every OS, no review thread is open, and its
  review's findings are fixed.
  - **This session, a Claude review stood in for Codex,** at the user's
    "merge without codex". Codex's usage limit was still answering every
    request. The classifier that gates this environment's actions refused a
    merge with no review at all, so the review is not optional.
  - When main moves after a pull request's CI ran, the pull request still
    has to merge cleanly. Its own suites must also pass on a trial merge
    with the new main. Every merge in this state that followed another was
    checked that way, or took main in and ran CI again.
- **Verify every review finding.** A real finding is fixed with a test and a
  negative control; one that does not reproduce gets a reply saying why.
- **Merge commits.** sdkgen, apidef, struct and sdkgen-langpack pull requests
  merge with a merge commit, and a branch takes main by merging it, never by
  rebasing. apidef-validate and model pull requests are squashed.
- **Releases go through the publish workflow's dispatch,** over OIDC, never
  from a workstation; the user asked for that this session. See Releases.
- **apidef commits** carry no trailers and no tool identifiers, and are
  authored as Richard Rodger.

## Notes for the next session

- **How a Claude review stood in for Codex.** Each round took two agents:
  - a fixer, given the confirmed findings (with the reviewer's evidence) and
    a page of notes, fixed each everywhere its construct lives, with a test
    that fails without the fix, and pushed;
  - a skeptic then reran the tests and the negative control, read the diff
    for what it missed, and returned sound or not with the problems.

  An unsound round started the next with the skeptic's problems as its
  findings. Most pull requests took one round:
  - three or more: #384 (seven), apidef #156 (four), and apidef-validate
    #38, sdkgen-langpack #33 and #382 (three each);
  - two: #371, #344 and sdkgen-langpack #35.

  The rounds also found defects nobody had filed: clojure's patch sent no
  request, #369 deleted the files of a phase switched off, and the
  redaction registry races. Budget a second round for any change across
  twenty targets.
